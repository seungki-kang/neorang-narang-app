# 문답 기록 검색

기준: GitHub main 6afb4b8603c3e3249b6b893257ffe7fc1fbe8102.
범위: CompletionHistoryPage와 새 회귀 테스트. DB·API·교재·인증 변경 없음.

- 기존 장 필터와 이름·상대방·과정 제목·은혜 내용·표시 날짜 검색을 AND로 결합.
- 여러 검색어는 모두 포함되어야 함. 대소문자 무시, 앞뒤/연속 공백 무시.
- 날짜는 화면 표시 형식 YYYY.MM.DD 기준. YYYY-MM-DD, YYYY/MM/DD도 지원.
- 총 완료 횟수는 전체 기록 기준 유지. 조건에 맞는 기록 수 별도 표시.
- 검색 결과 없음과 저장 기록 없음 구분. 검색어 지우기는 장 선택 유지.
- 검색어는 메모리에서만 사용하며 기록하거나 서버에 전송하지 않음.
- 검색으로 원본 기록 수정·삭제·정렬 순서 변경 없음.

검증: git diff --check 실행. Flutter/Dart SDK 부재로 정적 분석·신규 5개 테스트·기존 전체 테스트·APK 빌드는 NOT_RUN.
