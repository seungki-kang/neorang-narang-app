# 은혜 임시저장 및 복원 1.5
기준: 실행 검증 완료 1.4. 교재·DB schema·패키지 의존성 변경 없음.

## 변경
은혜 기록 페이지 진입 시 과정/참여자/고유 ID와 빈 초안을 먼저 저장.
입력 멈춤 300ms 후 저장, 앱 비활성화/화면 종료 때 추가 저장 시도.
저장 상태 및 실패 재시도 안내. 화면 이동 전에 저장 성공 확인.
단일 SharedPreferences 키, 직렬 쓰기, 손상 원본 덮어쓰기/삭제 금지.
홈에 이어쓰기/서명 이어가기 카드 제공. 미완료 은혜가 있으면 새 문답 시작 차단.
서명 이동 상태 보존. 완료 저장 시도 전 서명 시각·내용·동일 ID를 임시 기록에 저장.
완료 성공 및 다시 읽기 확인 후 관련 문답 초안과 은혜 초안 삭제.
완료 저장 후 정리 전에 종료된 경우 홈에서 완료 내용 일치를 확인 후 정리.
문답→은혜 이동 전에 수행하던 미확인 clear 호출을 제거해 마지막 질문 복귀 정보 보존.

## 검증
신규 8개: 직렬 저장/복원, 다른 세션 보호, 손상 보호, 서명 복원,
화면 자동저장/복원, 저장 응답 실패 후 재실행 재시도 중복 차단,
홈 이어가기, 완료 후 중단된 정리 복구.
기존 은혜 화면 테스트는 실제 임시저장 초기화/독립 mock fixture를 추가.
이외 기존 테스트 보존. 총 기대 31개.
패키지 해시/ZIP CRC/whitespace: PASS. Flutter/Dart/PowerShell: NOT_RUN.

## 한계
저장 완료 표시 전 강제 종료 시 마지막 입력 보존 보장 없음.
플랫폼 SharedPreferences의 OS 디스크 flush/기기 고장까지 무손실 보장하지 않음.
임시 기록은 해당 기기에 저장되며 암호화/클라우드 동기화는 구현하지 않았다.
서명만 누르고 완료 저장 시도 전 종료하면 다시 서명해야 한다.
실제 Android 재실행 수동 검증 필요. 테스트는 모의 저장소 기반.
