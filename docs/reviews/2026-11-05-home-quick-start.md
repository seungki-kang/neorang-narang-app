# 홈 빠른 시작

기준 커밋: 61c232defa6ee79c8de768f984f019b17a4a4b9e (PR #5 병합).
범위: home_page.dart, home_quick_start_test.dart, 본 문서. 교재·DB 스키마·API·로그인 변경 없음.

## 동작
- 저장된 본인 이름이 있으면 홈에서 혼자 바로 과정 선택. 상대방 값은 빈 값 사용.
- 최근 상대방은 목록을 열고 직접 선택해야 함께 과정 선택. 취소 시 이름 설정을 쓰지 않음.
- 기존 사용설명서/참여자 설정 경로 유지. 신규 사용자는 기존 경로 사용.
- 문답/은혜 초안이 있으면 빠른 시작 숨김. 탭 후 초안 다시 읽어 늦게 생긴 초안도 보호.
- 탭 중 중복 진입 차단. 선택 완료 후 기존 remember를 사용하여 최근 이름 순서 유지.
- 이름 읽기 오류는 별도 안내/재시도. 원본 오류 자료 덮어쓰기 없음, 기록 화면 접근 유지.
- 이름은 기존 로컬 설정에서만 읽고 서버·로그로 전송하지 않음. 새 공유/인증 동의 의미 없음.

## 검증
- 신규 위젯 테스트 8개 작성: 첫 사용, 혼자, 상대방 직접 선택/취소, 문답 초안, 은혜 초안,
  홈 로드 이후 초안, 손상 이름 설정, 연속 탭.
- Dart 구문 파서: 두 Dart 파일 오류 노드 없음. Flutter 타입 검사 대체가 아님.
- Flutter/Dart SDK 없음: 신규/전체 Flutter 테스트, analyze, APK, 실제 기기 확인 NOT_RUN.
- 배포·설치·커밋·push 미실행. 사용자 PC 설치기에 신규 테스트→분석→전체 테스트→APK 빌드 순서 포함.

## 남은 확인
작은 화면·큰 글씨 스크롤과 뒤로 돌아온 뒤 이름 갱신을 기기에서 확인.
이번 검사 결과를 운영 인증/동기화/강제 종료 복원 검증으로 확대하지 않음.


## 2026-11-06: 함께 하기 통합 — 이전 세 버튼 제안 대체

사용자 승인: 홈은 혼자 하기·함께 하기 두 버튼. 함께 하기에서 위쪽 이름 입력, 아래쪽 최근 함께한 분 목록, 함께 시작 확인 순서로 진행한다. 최근 선택은 입력란만 채우며 취소·뒤로가기는 이름 저장을 발생시키지 않는다. 선택한 이름을 수정하면 수정한 입력값을 사용한다. 빈 이름은 버튼을 비활성화한다. 최근 중복 제거·5명 제한은 기존 저장소를 재사용한다. 기존 참여자 설정 진입과 이름 수정·목록 삭제 기능은 기존 문답 시작하기 경로에서 유지한다.

함께 하기 직전과 입력 확인 직전에 미완료 초안을 다시 확인한다. 기존 문답·은혜·서명, DB 스키마, 서버 API, 교재는 변경하지 않는다.

이전 빠른 시작 8개·분석·전체 테스트·APK는 사용자 PC 출력에서 PASS였으며 새 통합 UI의 결과로 확대하지 않는다. 기존 빠른 시작 테스트의 상대 선택 시나리오만 새 확인 흐름으로 갱신하고 다른 검증은 보존한다. 후속 테스트 6개는 취소 보존·최초 입력·늦은 초안(홈/선택 중)·최근 선택 후 수정·중복 탭을 검사한다. 이 환경에서는 Flutter SDK 부재로 분석·테스트·APK NOT_RUN. Dart 구문 검사 및 패키지 해시 검증만 수행했다. 실제 앱·작은 화면·큰 글자 수동 확인은 별도다.
