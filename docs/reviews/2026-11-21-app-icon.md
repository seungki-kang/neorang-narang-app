# 앱 아이콘 교체: Flutter 기본 아이콘 → 너랑나랑 아이콘

기준 커밋: ab380be (main, PR #8 병합 직후).
범위: Android 런처 아이콘(기존 PNG 교체, adaptive·monochrome 추가), iOS AppIcon 전체, 아이콘 원본 SVG, 정적 테스트. 교재·DB 스키마·저장 로직·API·Dart 코드 변경 없음.

## 디자인
- 사용자 선택: 시안 C(글자형). 처음 올린 말풍선·하트 시안은 사용자가 너랑나랑에 맞지 않는다고 판단해 대체했다.
- "너·나" 두 글자와 가운데 점. JesusLife One 로고("J.")의 세리프 글꼴과 점 모티프, 보라색(`#6357A3`)을 이어받았다. 가운데 점은 연보라(`#B8AEDD`), 배경은 밝은 라벤더(`#F8F5FC`)다.
- 글자는 Noto Serif CJK KR Black(SIL Open Font License)의 글리프 윤곽을 도형(path)으로 변환했다. 원본 SVG는 글꼴 설치 없이 같은 결과로 렌더링된다. 글꼴 파일은 저장소와 앱에 포함하지 않는다.
- 작은 크기(iOS 40px 등)에서 읽히도록 Bold보다 두꺼운 Black을 선택하고 글자 간격과 점 크기를 키웠다.
- 원본: `docs/design/app_icon/`의 SVG 4개(iOS, Android 레거시, adaptive 전경, monochrome). 앱 번들에는 포함되지 않는다(pubspec assets 미등록).

## 변경
- Android
  - `mipmap-*/ic_launcher.png`(48dp 기준 5개 밀도): 옅은 테두리가 있는 둥근 사각형 배경을 포함한 레거시 아이콘. Android 7.1 이하용.
  - `mipmap-anydpi-v26/ic_launcher.xml` 추가: 배경 색(`values/ic_launcher_background.xml`), 전경(`ic_launcher_foreground.png`, 108dp), 테마 아이콘용 monochrome(`ic_launcher_monochrome.png`, 108dp). Android 8.0 이상은 기기 모양(원형·스퀘어클 등)에 맞춰 잘린다. monochrome은 Android 13 이상의 테마 아이콘에서 사용한다.
  - manifest의 `android:icon="@mipmap/ic_launcher"`는 그대로다.
- iOS: `AppIcon.appiconset`의 18개 PNG를 같은 파일명·크기로 교체. App Store 요구에 맞춰 모두 알파 채널 없는 RGB다. `Contents.json` 변경 없음.
- `test/app_icon_test.dart` 추가: iOS 아이콘 크기가 `Contents.json`과 맞고 알파 채널이 없는지, Android adaptive 선언과 밀도별 PNG 크기·투명도를 확인한다. 기존 테스트는 변경하지 않았다.
- web·macOS·Windows·Linux 아이콘은 스토어 대상이 아니어서 바꾸지 않았다.

## 데이터 영향
- 앱 식별자·저장 형식·DB 버전·migration 변경 없음. 기기 기록 영향 없음.

## 검증
- 정적 확인: 생성한 PNG의 크기·색 형식(iOS RGB, Android 레이어 RGBA)을 테스트와 같은 규칙으로 Python에서 확인해 불일치 0건. 두 XML 구문 확인.
- 시각 확인: 원형·스퀘어클 마스크, 테마 아이콘, iOS 모서리 마스크를 합성한 미리보기로 글자가 잘리지 않는지, iOS 40·58·120px에서 글자가 읽히는지 확인.
- Flutter/Dart SDK 없음: flutter analyze, 신규·전체 test, Android debug/release 빌드, iOS 빌드 NOT_RUN. PR의 CI(`Analysis and tests`, `Android debug build`)로 확인한다.
- 실기기 런처·iOS 홈 화면 표시 NOT_RUN.

## 남은 확인
- 스토어 등록용 그래픽(Google Play 512px 아이콘, 기능 그래픽)은 별도다. 512px은 `docs/design/app_icon/app_icon_ios.svg`에서 만들 수 있다.
- 시안 C는 사용자가 선택했다. 실제 기기 홈 화면에서 크기·색감 확인은 남아 있다.
