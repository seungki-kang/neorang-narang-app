# 공통 개발 원칙 1.0

상태: 적용 제안 / 기준일 2026-10-09
출처: CHGO Constitution 2.0, CHGO Master Context 1.0 Candidate, 바이브코딩 점검 체크리스트.
최신 승인 ACTIVE 기준이 우선한다. 이 파일은 교재 원문과 온톨로지를 대체하지 않는다.

- 승인된 JesusLife 의미와 문항을 임의로 재정의하지 않는다. 용어 충돌은 승인된 원문으로 확인한다.
- 완료·참여·작성 횟수는 학습 또는 훈련 근거이며 영적 성숙 점수가 아니다.
- 타인의 부당행위 책임과 자신의 내면 성찰을 구분한다. 안전과 보호가 우선한다.
- 개인 원문·이름·토큰을 로그와 오류수집에 넣지 않는다.
- 교회 소속, 함께 참여, 동일 로그인은 개인 기록 공유 동의가 아니다.
- 원문과 동의한 구조화 근거를 분리한다. AI 제안은 사용자 확인 없이 확정하지 않는다.
- 데이터 없음, 오류, 손상, 기회 없음은 서로 다르다. 손상 원본을 덮어쓰지 않는다.
- 앱·DB·콘텐츠·API 버전을 구분한다. 적용한 migration은 변경하지 않고 다음 migration을 추가한다.
- 변경 이유·영향·검증 결과를 기록한다. 미실행 검증은 NOT_RUN으로 표시한다.
- DB가 변경된 앱은 이전 바이너리 설치만으로 롤백했다고 주장하지 않는다.

범위: 공통 원칙의 코드 구현 여부는 각 프로젝트 점검 보고서에서 별도로 확인한다.
